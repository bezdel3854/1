# Проверки 25.10.2026

## Выполнено

- `python -m unittest discover -s tests -v`: 40 тестов, все успешны на Python 3.12.14.
- `python -m compileall -q bingx_bot`: успешно.
- Скачаны реальные публичные BingX BTC-USDT/ETH-USDT: 8544 закрытые 15m-свечи и 267 funding settlements на каждый символ. Проверены OHLCV, непрерывность, синхронизация, funding coverage и SHA256. Часовые свечи построены из 15m без включения незакрытого часа.
- Выполнены полный бэктест, отдельные development/holdout, forward-сегменты с фиксированными параметрами и стресс издержек; результаты в `reports/validation`.
- Live public API smoke: contracts, bookTicker, fundingRate, premiumIndex, server time, klines. Реальная форма bookTicker (`book_ticker`, snake_case) проверена ответом API и поддержана клиентом.
- `python -m bingx_bot.cli paper --db runtime/smoke.sqlite --once`: успешный цикл, equity 1000, позиций 0. Это проверка подключения и жизненного цикла, а не доказательство торговли или прибыльности.
- Сценарии исполнения: обе стороны Long/Short, all-in risk <=5 USDT при стопе без гэпа, комиссия и funding, гэп с превышением бюджета, двойное касание stop-first, отсутствие использования будущих свечей, отсутствие использования внутрисвечной выручки до open, next-open, закрытие конца теста.
- Сценарии перезапуска: восстановление состояния, недопустимость второго writer, неизменность конфига счёта, защита от повторного сигнала, потеря только незакоммиченных изменений, STOP, устаревшие данные и пропущенные окна сигналов.

## Не выполнено / не доказано

- Нет реальных заявок, реальных денег и exchange testnet orders. Paper fills существуют только в SQLite.
- GitHub Actions успешно выполнил 40 тестов, бэктест, Docker build и минимальный запуск образа: https://github.com/bezdel3854/1/actions/runs/40180071957 . Локального Docker daemon нет; сетевой paper-worker внутри облачного контейнера ещё не проверен.
- Нет активного сервиса Railway, проверки Volume permissions и перезапуска в облаке; подготовлены файлы/инструкция.
- Нет многомесячного forward paper-trading. Короткий smoke не заменяет его.
- Нет годовой истории, точного order-book backtest, исторических tier/rule snapshots и реальной модели ликвидации BingX.
- Убыточный результат не исправлялся подбором параметров на уже просмотренной выборке. Оснований для реальной торговли не получено.

57 тестов успешно проверяют старый движок и новые модели: инвариантность сигнала при добавлении будущих свечей, исключение текущего часа из пробойного канала, момент активации trailing, гэп через новый стоп, выход на следующем open, задержку входа на одну свечу, диагностику bootstrap, отсутствие входов в наблюдательном режиме и запрет смены модели на существующем счёте. Числовой результат прежнего baseline сверяется с сохранённым отчётом.

Live smoke `regime_composite` завершён в `observe_only=true`: equity=1000, позиций=0. Это тест работоспособности, не длительное forward-наблюдение. Отчёты: `reports/approaches`, первоисточники: `research/TRADERS_AND_SOURCES.md`, план: `research/EXPERIMENT_PLAN.md`. Все восемь вариантов отклонены; подтверждённой прибыльной стратегии не найдено.


## Расширенный поиск и зафиксированный кандидат

65 тестов проходят, включая причинность кэшированных 1h-признаков, границы часов, размер фиксированной сетки 256, воспроизведение сделок на следующем open и сверку чистого streaming-модуля со всеми сигналами исследовательского расчёта на BingX. Финальный кандидат выбран на 2023/2024 до открытия 2025; hash исходного протокола сохранён. Дополнительный непрерывный стресс показал остановку по просадке и включён в отчёт. Нового выбора после финального года не было. Многонедельного forward paper пока нет.
